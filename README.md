Solmar Bay — an original open-world crime game in the browser. Drive and walk a sun-soaked island city, run six story jobs for Mara, steal cars, dodge the police and their helicopter, and don't get caught. Built with three.js (vendored under `game/vendor/`) and plain Node for the entrypoint — no build step, no network requests, your progress saves locally.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. WASD drive / walk · mouse aim · click shoot · E enter a car · Shift sprint · Space handbrake · R radio · P pause · M mute.
